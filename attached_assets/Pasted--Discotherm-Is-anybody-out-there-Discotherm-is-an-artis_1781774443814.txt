# Discotherm

**Is anybody out there?**

Discotherm is an artist discoverability diagnostic tool, built for the [Musixmatch Musicathon 2026](https://www.musixmatch.com/pro/api/musicathon).

Most music tools measure how popular an artist is. Discotherm measures something different: how *discoverable* they are — and where, specifically, the system is failing them. Discoverability is treated here as a property of the system, not of listener taste: a catalogue can be excellent and still be structurally invisible to the algorithms and curators that decide what gets surfaced. That invisibility is a real, measurable harm to artists, distinct from a listener simply not finding something they'd enjoy.

Enter any artist name and get a discoverability score out of 100, built from five diagnostics, each with a concrete, scale-aware recommendation.

## The five diagnostics

- **Catalogue depth** — what proportion of the catalogue carries full lyric and synced-lyric metadata, the baseline for being visible to lyric-driven discovery surfaces
- **Stream concentration** — whether listeners explore the full catalogue, or only ever reach the same two or three tracks
- **Playlist reach** — editorial vs. organic playlist placement, the clearest available signal of human curation vs. algorithmic luck
- **Mood coherence** — using Musixmatch's lyric analysis API, a cosine-similarity score across an artist's mood vector profile, measuring whether their emotional identity is coherent enough for recommendation systems to confidently categorise them
- **Platform gap** — cross-platform presence and engagement (Spotify, Apple Music, TikTok, YouTube, Shazam, Deezer, SoundCloud), flagging where real fan activity (TikTok creates, Shazams) isn't converting into platform-level discovery credit

Each diagnostic's recommendation adapts to the artist's scale (emerging / mid-tier / major, inferred from monthly listeners) — a 0.5% editorial playlist share means something very different for an unsigned artist than for a global superstar, and the tool's language reflects that.

## APIs used

**Musixmatch Pro API**
- `artist.search`, `track.search` (with `f_artist_id`) — catalogue retrieval and artist disambiguation
- Track metadata fields `has_lyrics`, `has_richsync`, `num_favourite` — catalogue depth and stream concentration
- `track.lyrics.analysis.get` — mood/theme extraction, powering the Mood Coherence diagnostic

**Songstats API**
- Artist stats — monthly listeners, followers, popularity score
- Playlist data — total and editorial playlist placement counts
- Cross-platform stats — Spotify, Apple Music, TikTok, YouTube, Shazam, Deezer, SoundCloud presence and engagement (TikTok creates, Shazam counts)

**ElevenLabs**
- Text-to-speech narration of the generated report

## Tech stack

- **Backend:** Python, FastAPI
- **Frontend:** vanilla HTML/CSS/JS, no framework
- **PDF export:** ReportLab
- **Fonts:** Space Grotesk (headers/scores), Inter (body)
- **Hosting:** Replit

## Running locally

```bash
git clone <this-repo>
cd discotherm
pip install -r requirements.txt
```

Set the following environment variables (or a `.env` file):

```
MUSIXMATCH_API_KEY=your_key_here
SONGSTATS_API_KEY=your_key_here
ELEVENLABS_API_KEY=your_key_here
```

Then run:

```bash
uvicorn main:app --reload
```

The app will be available at `http://localhost:8000`.

## Known limitations

- **`num_favourite` as a stream proxy.** Musixmatch's API does not expose actual stream counts on this plan, so Stream Concentration uses track favourites as a proxy. This is noted directly in every report.
- **Artist name disambiguation.** Musixmatch's `track.search` is a fuzzy, tokenized search, not an exact artist lookup. Short or common-token artist names (e.g. "i cani") can initially get buried by unrelated, more popular artists matching individual words. Discotherm resolves this by probing candidate `artist_id`s via `f_artist_id` and selecting the best match by name similarity and catalogue size — but this remains an imperfect heuristic, and is itself a small, concrete example of the kind of algorithmic discoverability bias the tool is designed to detect.
- **Mood Coherence sample size.** Mood analysis runs on an artist's top 15 tracks by rating, not their full catalogue, for performance reasons. Artists with fewer than 5 tracks returning valid analysis data are marked `insufficient_data` rather than scored.
- **Catalogue/track counts are not exhaustive.** Track counts reflect paginated `track.search` results, not a guaranteed complete discography, and may vary slightly between runs as the underlying catalogue is indexed.

## Why this matters

Discoverability isn't a UX inconvenience — it's an economic and creative harm that falls unevenly across artists, genres, and even, as we found while building this, artist names. Discotherm makes that harm visible, measurable, and hopefully actionable.
